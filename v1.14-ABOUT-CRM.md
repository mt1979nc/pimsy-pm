## Contact cards

- **Implementation team** — project staffing roles from template assignees on create (`applyRoleMemberships`), plus the lead/co-lead, plus people assigned on Kickoff parent tasks.
- **Practice contacts** — live `user` rows for the customer account. Invite, Edit (name / title / phone), or revoke refreshes every About for that practice. No denormalized copy, so cards cannot go stale.

## HubSpot

- Paste the deal URL on **New project**, **Prism → Add to roster**, or **About**.
- PATH stores a clear outbound https link (`javascript:` refused).
- Optional pull: set `HUBSPOT_ACCESS_TOKEN` (private app, `crm.objects.deals.read`). Staff About shows deal name/stage when the token works. When unset, the Open HubSpot link is enough.
- Portal never receives the URL or the pull.

## Custom fields

Keys that duplicate first-class columns (HubSpot, CRM, Zoom, Prism, notes, onboarded) are stripped on save. Remaining extras (timezone, preferred contact, …) stay staff-only.
