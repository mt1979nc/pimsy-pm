# v1.10 Forecast — implementation report

**Date:** 2026-09-12  
**Branch:** `cursor/v1.10-forecast-6002`  
**Version:** 1.10.0  
**Architecture:** Native Postgres in pimsy-pm — **no** Prism Azure SQL dual-write or dual-read.

## What shipped

1. **Management Forecast** (`/management/forecast`) — OWNER / ADMIN / MANAGER
   - Weekly hours from scoped `estimatedHours` (or `customHoursPerWeek`) across kickoff → current go-live
   - Team load cards, department headroom, peak week, hire-now
   - Pipeline excluded from active load
   - Capacity-exempt staff listed but excluded from dept cap / headroom / hire-now
   - Owner split applied to lead + co-lead
   - Slip impact: later go-live dilutes weekly hours unless custom hrs/wk is set
2. **Forecast+ weights** listed on the Forecast page (estimator constants in `src/lib/estimator.ts`)
3. **Analysis exclusions** — primary averages skip SENSORI / MHC / LECHRIS by default; editable on Forecast (`org_settings.forecast_analysis_exclusions`)
4. **Capacity report** uses the same weekly-hours model for the forward table; open-task snapshot remains
5. **Authz:** specialists redirected from `/management/*`; customers never see Forecast (staff nav + portal layout)
6. **v1.11 hook:** `src/lib/prism-dual-read.ts` + `PRISM_SQL_CONNECTION_STRING` in `.env.example` (unused)

## Azure migrate

Deploy-to-main already runs `npm run db:migrate` in GitHub Actions.

```bash
# DATABASE_URL = Azure Flexible Server connection string
npm run db:migrate
```

Migration: `drizzle/0011_forecast.sql` (journal idx 11). Adds nullable `org_settings.forecast_analysis_exclusions`. Null still means the locked default list in code. No Prism SQL secrets required.

## Gaps left for v1.11 dual-read

- Do **not** POST Prism `saveState` from PM
- Point Director / Pipeline routines at pimsy-pm **and** dual-read live Prism (`pimsy-prism-sql.database.windows.net` / `prism`) before write cutover
- Session-only hire placeholders, phase-curve (vs even-spread) weekly model, RCM financial forecast — still later
- Standalone Prism (nice-rock / purple-beach) stays writable by humans until dual-read is proven
