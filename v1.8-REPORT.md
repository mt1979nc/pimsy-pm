## Assumptions

- Column `is_director` / field `isDirector` (matches `isActive` style; brief’s `is_director`). User brief also said `director` — same meaning.
- Project fields use brief names: `owner_split_percent`, `custom_hours_per_week` (user brief’s `ownerSplitPct` / `customHpw`).
- `prism_status` values: `active` | `pre-kickoff` | `pipeline`; stalled/special via `prism_note`.
- Mapping: pipeline→customer `PROSPECT` + project `NOT_STARTED`; pre-kickoff→`ONBOARDING`/`NOT_STARTED`; active→`ONBOARDING`/`IN_PROGRESS`. LIVE/AT_RISK/CHURNED customers are not demoted on edit.
- Initial go-live locks after first non-null value (form field disabled).
- Capacity load remains task-hour based (`/reports/capacity`) until v1.9; dept headroom copy on Team excludes capacity-exempt hrs.
- No full Forecast+ weights / hire scenarios / Prism SQL connector.
