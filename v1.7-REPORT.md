## How to test

1. Migrate DB (`npm run db:migrate` / setup reset as you prefer).
2. Sign in as staff with project write access.
3. Open a project → **About** → edit HubSpot / Prism / CRM / Zoom / notes / custom `key=value` lines → Save.
4. Sign in as a customer on that project → Areas → **About** → confirm notes, Zoom link, acronym only (no HubSpot/Prism/CRM key).
5. Staff: project **Messages** → open a SHARED thread → set Waiting on (PIMSY / customer) → confirm badge + aging; reply as customer vs staff and confirm auto-flip.
6. Leadership: **Waiting on** (`/reports/waiting-on`) and Dashboard “Waiting-on threads” / WIP rollup link — open SHARED threads grouped by project with PIMSY vs customer counts.
7. Confirm primary buttons still `#113c64` + white; `globals.css` still does **not** set `button { color: inherit }`.
8. Sign-in page / version string shows **1.7.0**.
