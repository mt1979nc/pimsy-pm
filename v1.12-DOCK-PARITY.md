## 0. Migrate, then seed catalogs

From a host that can reach PATH Postgres (Azure Cloud Shell or CI):

```bash
export DATABASE_URL='postgresql://…'   # paste from App Service → Configuration. Do not invent.
npm ci                                 # if this shell has no node_modules
npm run db:migrate
npm run db:seed -- --templates-only    # refreshes playbooks + library placeholders + Learning Center
```

`--templates-only` does **not** create demo customers. It **does** upsert Learning Center sections and placeholder files. Uploaded (non-placeholder) library files are kept.

## 1. Prune customers not on current Dock WIP (active book only)

Allowlist ships in-repo: **`content/dock-wip-allowlist.json`** (Dock Implementation WIP as of **2026-09-14**). `npm run db:cleanup:non-dock` uses that file by default. You can still pass a JSON/CSV overlay.

Accepted overlay shapes:

- JSON array: `["BHC","CEDAR"]`
- `{ "acronyms": ["BHC"] }`
- Dock snapshot: `{ "workspaces": [{ "acronym": "BHC", "name": "…" }] }` (same as `db:import:dock-wip`)
- CSV with an `acronym` column, or one acronym per line

```bash
# Cloud Shell — DATABASE_URL already exported
npm run db:cleanup:non-dock
# review DELETE vs KEEP lists
npm run db:cleanup:non-dock -- --apply
```

### Default rules (locked)

| Keep | Delete |
|------|--------|
| Acronym on `content/dock-wip-allowlist.json` | Active / pre-kickoff / pipeline / other WIP **not** on the allowlist |
| `status` COMPLETED or CANCELLED | Dock test/draft names (DRAFT Impl, MT Test, Test Dock, MT Testing, process-improvement) unless Alexander allowlists the acronym |
| `archivedAt` set | |
| `actualGoLiveDate` in the past | |
| Customer LIVE/CHURNED when the project is not still active WIP | |
| Named staff (alexander@, jeremy@, …) | Portal contacts only when their customer is deleted |

`--keep-prism-analytics` also keeps **pipeline-only** analytics sites that are not on Dock WIP. Default is to prune those with the rest of the active book (completed Prism sites stay).

Prism completed / pipeline-only sites **not** in Dock WIP:

- Completed / actual-end-in-the-past → **kept** (historical Forecast/Analysis).
- Pipeline-only still in the active book → **delete candidates** unless `--keep-prism-analytics`.

The script never deletes playbooks.

## 2. Resync playbook nested tasks from Dock template

Hypothesis: earlier Dock WIP import could leave a **shallow** task tree if the template lacked `parent_task_id` at import time. Current seed already nests Dock section groups (`G(...)` in `template-implementation.ts`).

```bash
npm run db:seed -- --templates-only          # if not done in step 0
npm run db:resync:playbook-from-dock         # dry-run
npm run db:resync:playbook-from-dock -- --apply
# optional: --only CEDAR,BHC
```

Matching is by **normalized title inside a phase**. Existing DONE / IN_PROGRESS / BLOCKED rows keep status and `completedAt`. Missing nested tasks are inserted as TODO. Missing checklist rows and default files are added. Extra custom tasks are never deleted. **Completed / cancelled projects are skipped.**

After apply, spot-check one WIP site: Kickoff should show Pre-Kickoff → children; Core training should show Training 1 → Schedule / Recording / etc.

If a Dock scrape later shows different titles, update `src/db/template-implementation.ts` and re-run seed + resync (still match-by-title).
