## 2. Resync playbook nested tasks from Dock template

Hypothesis: earlier Dock WIP import could leave a **shallow** task tree if the template lacked `parent_task_id` at import time. Current seed already nests Dock section groups (`G(...)` in `template-implementation.ts`).

```bash
npm run db:seed -- --templates-only          # if not done in step 0
npm run db:resync:playbook-from-dock         # dry-run
npm run db:resync:playbook-from-dock -- --apply
# optional: --only CEDAR,BHC
```

Matching is by **normalized title inside a phase**. Existing DONE / IN_PROGRESS / BLOCKED rows keep status and `completedAt`. Missing nested tasks are inserted as TODO. Missing checklist rows and default files are added. Extra custom tasks are never deleted. **Completed / cancelled projects are skipped.**

After apply, spot-check one WIP site: Kickoff should show Pre-Kickoff → children; Core training should show Training 1 → Schedule / Recording / etc.

If a Dock scrape later shows different titles, update `src/db/template-implementation.ts` and re-run seed + resync (still match-by-title).

## 3. Default attached items (Discovery Wizard, billing sheets)

PATH stores task attachments in `file_asset` (`kind` FILE / IMAGE / LINK). Template defaults live in `library_asset` + `template_task_attachment`, then **clone** onto live tasks as their own `file_asset` rows (`library_asset_id` set). Dock WIP import and new-project materialize both copy them. Resync backfills missing clones and **never deletes** user-uploaded files.

Placeholders (markdown, no PHI) live in `content/default-attachments/` and seed into the **file library**. Real Dock binaries go in **`content/template-attachments/`** (gitignored except README) — see that folder's runbook.

| Slug | Kind | Attaches to (task title) |
|------|------|--------------------------|
| `discovery-wizard` | **LINK** `https://calm-mud-0fe119810.7.azurestaticapps.net/` | Guided Discovery Meeting, Schedule: Workflow Guided Discovery, Organization Details Form, Clinical Workflows |
| `billing-spreadsheet` | FILE (placeholder until pack/UI replace) | Complete & Upload Billing Spreadsheet — Accepted Payers, Modifiers |
| `billing-questionnaire` | FILE | Billing Questionnaire (submit + upload completed files), Review Billing Questionnaire Data Sheet (Site Configuration) |
| `clinical-workflows-sheet` | FILE | Clinical Workflows, Review Clinical Workflow Data Sheet |
| `organization-details-form` | FILE | Organization Details Form |
| `rcm-intake-questionnaire` | FILE | Complete RCM intake questionnaire |

**Alexander:** Confirm Discovery Wizard is a clickable attachment on a Guided Discovery task (not only a Learning Center card or a URL in the description). For billing spreadsheet / questionnaire binaries:

```bash
# after copying Dock xlsx/pdf/docx into content/template-attachments/
npm run db:upload:template-attachments          # dry-run
npm run db:upload:template-attachments -- --apply
npm run db:resync:playbook-from-dock -- --apply
```

Or Owner/Admin → **Templates → File library** (`/library`). Storage is the same Azure Blob / `UPLOAD_DIR` pattern as task uploads. New workspaces copy the current library row onto matching tasks.

Do not commit production binaries, connection strings, or invented spreadsheet bytes.
