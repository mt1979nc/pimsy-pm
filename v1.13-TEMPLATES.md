# v1.13 Template area

PATH playbook management for Alexander: edit the Dock Implementation template
**in PATH** (descriptions, nested tasks, training checklists, default files),
duplicate a path without touching the four site-creation options, and resync
WIP without hanging. Does **not** call the Dock API or edit live Dock Spaces.

**Version:** 1.13.0 (`APP_VERSION` / `package.json`).

PATH + Prism naming is unchanged.

## What was already good (v1.9–v1.12)

- Add/remove/reorder phases and tasks (HTML5 DnD)
- Four playbook paths on New project
- Optional areas excluded on create; per-project N/A
- Nested parent tasks in the seed + resync
- Default attachments clone onto matching PATH tasks (v1.12.2)
- Training checklists on **live** tasks
- File library replace-binary
- Materialize on new workspace

## What this slice adds

1. **Editor fidelity** — task description, nest under a section, add/remove
   training areas, attach/detach library files.
2. **Navigation** — Settings → Playbooks; Setup → Templates + File library;
   hub strip on `/templates`, `/library`, editor.
3. **Duplicate** — inactive custom copy (unique `code`, `playbookPath` null).
   Rename on the playbook card. The four paths stay unique.
4. **Bulk optional areas** — counts, filter, Mark optional / Include always;
   custom area keys.
5. **Resync** — batch queries, progress logs, 180s timeout, `--limit` /
   `--only` / `--timeout-sec`. Inserts now copy checklists + attachments too.

## Azure Cloud Shell (resync)

No Dock credentials. Copy `DATABASE_URL` from App Service → Configuration.

```bash
export DATABASE_URL='postgresql://…'   # quotes; do not commit
npm ci                                 # if this shell has no node_modules
npm run db:seed -- --templates-only    # optional catalog refresh
npm run db:resync:playbook-from-dock   # dry-run; prints [Ns] progress
npm run db:resync:playbook-from-dock -- --apply
```

Useful flags:

| Flag | Meaning |
|------|---------|
| `--only CEDAR,BHC` | One or more acronyms / codes / ids |
| `--limit 5` | First N eligible WIP projects |
| `--timeout-sec 120` | Stop instead of hanging (default **180**) |
| `--timeout-sec 0` | No cap |
| `--seed` | Refresh catalogs even on dry-run |
| `--apply` | Write (also refreshes catalogs) |

If a previous dry-run sat silent: that was per-task N+1 queries. This version
logs every project and exits with a partial plan + `TIMED OUT` rather than
spinning. Re-run with `--only` for remaining codes. Completed / cancelled
sites are skipped. User uploads are never deleted.
