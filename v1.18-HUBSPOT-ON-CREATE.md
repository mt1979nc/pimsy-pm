## Read-only

PATH **GETs** `https://api.hubapi.com/crm/v3/objects/deals/{id}`.

It does not create, update, or delete HubSpot records. It does not call the deal search endpoint, because that API is a POST. The private app needs `crm.objects.deals.read` only.

## What staff do

Paste a HubSpot deal URL on **New project**, **Prism → Add to roster**, or **About → Edit site profile**.

| PATH field | HubSpot property | When it writes |
|---|---|---|
| `projects.hubspotDealUrl` | the pasted URL | Always, including a clear |
| `projects.contractDate` | `closedate`, or `HUBSPOT_DEAL_CONTRACT_DATE_PROPERTY` | Only when the PATH field is empty |
| `projects.expectedArr` | `amount`, or `HUBSPOT_DEAL_ARR_PROPERTY` | Only when the PATH field is empty |

A custom property wins when it has a value. An empty custom value falls back to `closedate` / `amount`. Invalid property names fall back to those defaults.

Clearing the deal URL does **not** wipe contract date or expected ARR. Staff may have edited them on Executive.

About still shows deal name, stage, and close date. **Pull from HubSpot** on About (shown when a deal id is linked and the token is set) fills the same empty CEO fields. It does not overwrite.

## Token unset

Store the URL only. Create and save succeed. No error is shown for the missing token.

## Portal

The customer portal and Customer view do not receive the token, the deal URL, contract date, or expected ARR. Those columns are omitted from the portal project select.
